# AiVisibility

## Швидкий старт

```
uv sync                      # залежності (Python >= 3.12)
cp .env.example .env         # додати OPENAI_API_KEY (і ANTHROPIC_API_KEY за потреби)
uv run pytest                # тести (офлайн)
uv run ruff check .          # лінтер
```

Порядок скриптів: `discover_brands` → `generate_queries` →
`run_prober --dry-run` (потім реальний запуск з `--max-budget-usd`) →
`detect_mentions` → `analyze_mentions` → `build_convergence_curves` /
`estimate_sample_size` → `adaptive_sampling_report`. Процес розробки —
`docs/sdlc.md`.

## Методологія: скільки запитів потрібно на движок

Довірчий інтервал mention rate конкурента звужується зі зростанням n
приблизно за формою `1/sqrt(n)`. На наявних даних пілоту (Stripe/Paddle,
2 бренди) ціль ±5 в.п. ще не досягається: на n=36 (Claude) ширина CI ≈9.7
в.п., на n=24 (OpenAI) — ≈9.2 в.п. Екстраполяція форми кривої дає
орієнтир ≈126 запитів на движок для Claude і ≈71 для OpenAI. Це **емпіричний
орієнтир для нашого сетапу** (ці два бренди, fintech-ніша, ці движки), а
не універсальна формула мінімального розміру вибірки — таку строгу
параметричну формулу автор методології (Sielinski, arXiv:2603.08924) сам
залишив окремою майбутньою роботою. Деталі методу й повний вивід —
`docs/weeks/week4.md`.

## Методологія: адаптивний семплінг

Замість рівномірного round-robin по (бренд, движок)-парах, адаптивна
стратегія на кожному кроці йде туди, де зараз найширший bootstrap CI серед
ще не стабілізованих конкурентів ("expected variance reduction"). За
однаковий фіксований бюджет викликів це дає суттєво точніший результат:
для середньої ширини CI по всіх 20 відстежуваних сутностях ціль ±5 в.п.
досягається на **68% менше викликів** (143 проти 451); для найгіршого
(max) відстежуваного конкурента — на **42% менше** (~891 проти ~1542, обидва числа — екстраполяція,
не пряме спостереження). Цікавий побічний, чесно задокументований
результат: якщо метою є "щоб КОЖЕН конкурент незалежно досяг цілі"
(а не фіксований спільний бюджет), переставляння порядку викликів
різниці не дає — арми статистично незалежні, тож сумарна кількість
викликів адитивна й не залежить від порядку. Деталі й повний метод —
`docs/weeks/week5.md`.
